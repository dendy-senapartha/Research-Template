# Publication Folder Template

Salin direktori ini menjadi `publications/PUB-001/` atau ID berikutnya. Tulis naskah pada `manuscript/article.tex`. Tambahkan direktori `figures/`, `tables/`, `supplementary/`, `submission/`, `reviews/`, dan `final/` hanya saat diperlukan.

Metadata `publication.yml` harus mencerminkan status sebenarnya, bukan rencana yang dianggap sudah terjadi. Untuk format publikasi, ganti `article` class sesuai template resmi penerbit.
