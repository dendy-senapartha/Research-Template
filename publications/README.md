# Publication Management

Setiap publikasi memakai identifier stabil: `PUB-001`, `PUB-002`, dan seterusnya. Catat setiap publikasi pada `publication-register.csv`.

Buat direktori `PUB-XXX/` dengan menyalin isi `_template/`, lalu isi metadata `publication.yml`. File `article.tex` pada template merupakan artikel LaTeX generik, **bukan** format final suatu jurnal atau prosiding.

Rujuk evidence dan artifacts dari `research/` dengan identifier, versi, dan commit SHA. Jangan mengisi target venue, status submission, DOI, atau temuan yang belum terverifikasi.
