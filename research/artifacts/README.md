# Research Artifacts

- `working/`: hasil sementara, belum terverifikasi.
- `validated/`: hasil yang sudah melewati quality gate dan memiliki bukti validasi.
- `frozen/`: versi terkunci yang digunakan sebagai basis analisis atau publikasi.

Pemindahan antarstatus harus didukung catatan keputusan/validasi dan nomor versi; jangan menganggap penempatan file sebagai bukti validasi.
