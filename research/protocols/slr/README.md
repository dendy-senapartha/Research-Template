# Literature Review / SLR

Opsional. Jika menjalankan SLR, dokumentasikan protokol pencarian, database, query, rentang tahun, kriteria inklusi/eksklusi, deduplikasi, screening, quality appraisal, ekstraksi, dan sintesis. Simpan raw records pada `research/evidence/`, script pada `scripts/`, serta keputusan analitik di governance.
